# Intent: Research matching users to their officials

## Outcome

Find an answer to this question, with enough supporting evidence that the project can make a decision:

> How is a user matched to their officials (two senators and one House representative) on a static page with no API key? Options include picking a name or state versus entering an address or ZIP code.

## Background

This is one of three open questions recorded in [.agent_context.md](../../.agent_context.md) for the Congressional Contact project: a static web page, ideally one file, with no backend, accounts, or API keys. It lets a phone user save their two senators and their House representative as full-detail contacts. The main user can name their own House representative; helping users who cannot is a lower priority.

## Scope

Answering the question above. Choosing the final design and building it are separate work.

## Acceptance

A written answer to the question that names its sources, states the practical options and their tradeoffs against the project's constraints, and notes anything that stayed uncertain.
