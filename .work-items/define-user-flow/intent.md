# Define User Flow: intent

## Intended outcome

Define the high-level experience a person has when using Congressional Contact. Describe the sequence of user actions and site responses so that later website design follows the intended flow.

## Approach and scope

Interview the owner to understand the experience they expect from the page, then capture the agreed flow. Use the existing [project context](../../.agent_context.md) as background, preserving settled decisions unless the owner explicitly changes them.

This work describes behavior and experience. Visuals, styling, and layout are outside its scope, apart from the expressly agreed help-overlay interaction. The completed interview's approved decisions are recorded in [user experience flows](../../design_notes/user-experience-flows.md), which is the canonical flow deliverable rather than a duplicate specification in this work-item folder.

## Deliverable

Save the agreed user experience flow in the root-level [design_notes directory](../../design_notes/), with enough context for later website design to use it without needing the original conversation.

The interview and flow definition are complete and the deliverable has been saved. Implementation and verification of the exact phone saving instructions are subsequent work; see the deliverable's handoff section.
